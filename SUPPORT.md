# Support

Read [Getting started](docs/getting-started.md) or [Patches](docs/patches.md).
For help, open an [issue](https://github.com/altophp/code-diff/issues) with PHP and
package versions, minimal old/new text or a patch, options, expected result,
and the actual exception or output. Preserve line endings and newline-at-EOF
information. Remove secrets and private file contents before sharing.
